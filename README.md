# Portfolio-Website
Personal portfolio site featuring my work, built with GSAP + Lenis motion and a custom interactive design with light/dark themes.

# sahilgohel.com

My personal portfolio website — live at [sahilgohel.com](https://sahilgohel.com).

An interactive portfolio featuring scroll-driven animations, a revolving
project gallery, and light/dark themes.

## Built with
- HTML, CSS, JavaScript
- GSAP + ScrollTrigger + SplitText (animation)
- Lenis (smooth scroll)
- Fonts: Inter, Fraunces, JetBrains Mono
- Deployed on Vercel

## Structure
- `index.html` — main page
- `style.css`, `base.css` — styles
- `app.js` — animations and interactions
- `assets/` — images and resume
